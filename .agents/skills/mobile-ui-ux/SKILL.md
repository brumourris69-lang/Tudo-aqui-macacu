# Mobile UI and UX

- Inspect the app's current design system, navigation, and neighboring screens before proposing visual changes.
- Optimize the flow for clear hierarchy, predictable navigation, readable content, and one obvious primary action.
- Specify loading, empty, error, success, disabled, and permission-denied states where applicable.
- Check small phones, large text, safe areas, keyboard visibility, touch target size, semantics, and contrast.
- Prefer subtle motion and reusable components that match the established identity; avoid decorative complexity without user value.
- Validate with relevant widget tests and screenshots only when visual tooling is authorized and available; distinguish rendered evidence from design review.
