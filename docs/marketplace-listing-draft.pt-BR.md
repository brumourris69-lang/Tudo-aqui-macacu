# Ficha das lojas — rascunho da versão 1.0

**Estado:** material interno para revisão; não publicado nem enviado às lojas.
**Idioma:** português (Brasil).
**Produto:** Tudo Aqui Macacu.

Este texto descreve somente recursos previstos no recorte 1.0 confirmado:
catálogo local por categorias, perfis públicos de estabelecimentos, Explorar
Macacu e Utilidades da Cidade. Não anuncia busca global, avaliações, propostas,
votos, vagas, notificações push, pagamentos ou data de lançamento.

## Artes e capturas

- Usar o ícone oficial do app já existente no projeto, sujeito à conferência
  contra os requisitos atuais de cada loja antes do envio.
- Capturas precisam vir do build final de distribuição e mostrar telas reais,
  sem fixtures, dados pessoais, conteúdo indisponível ou recursos adiados.
- Sequência proposta: Home; categorias; lista de estabelecimentos; perfil
  público; Explorar Macacu; Utilidades da Cidade.
- Não usar capturas do MEmu/Emulator como arte final sem conferir resolução,
  estado da interface e ausência de dados sintéticos.
- Vídeo promocional: não preparado nem necessário neste rascunho.

5. Gerar capturas reais do build candidato Android/iOS.
6. Preencher categoria, classificação etária, declarações de dados e

7. Conferir os limites de caracteres e políticas novamente ao preencher os
